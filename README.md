## 🌐 互動式網頁界面

### 檔案位置
`code/index_comprehensive.html`

### 界面特色

#### 1. **三大主選單**
- **種族 (Races)** - 瀏覽所有種族和子種族
- **職業 (Classes)** - 查看職業、子職業和特性
- **法術 (Spells)** - 搜尋和篩選法術

#### 2. **種族界面功能**
- 🔍 即時搜尋（中英文）
- 統計面板：總種族數、總子種族數
- 卡片式瀏覽：顯示速度、子種族數量
- 詳細檢視模態框：
  - 基本資訊（速度、體型、語言、年齡）
  - 種族特質完整描述
  - 子種族列表（可展開查看詳情）

#### 3. **職業界面功能**
- 🔍 即時搜尋（中英文）
- 統計面板：總職業數、總子職業數、總特性數
- 卡片式瀏覽：顯示生命骰、子職業數量
- 詳細檢視模態框：
  - 基本資訊（生命骰、豁免、熟練）
  - **分級特性顯示**：1-20級特性按等級組織
  - 子職業列表（顯示描述預覽）

#### 4. **法術界面功能**
- 🔍 即時搜尋（中英文、職業）
- **環級篩選器**：全部、戲法、1-9環
- 統計面板：總法術數、戲法數、環級法術數
- 顏色編碼：每個環級使用不同顏色
- 詳細檢視模態框：
  - 施法資訊（時間、射程、成分、持續）
  - 完整效果描述
  - 高環施放說明
  - 可施放職業

#### 5. **UI/UX設計**
- 🎨 現代漸層配色（紫藍色主題）
- 📱 響應式設計（手機/平板/桌面）
- ⚡ 流暢動畫效果
- 🔄 即時搜尋和篩選
- 💫 懸停效果和互動反饋
- 📊 統計數據可視化
- 🎯 模態框詳細檢視

#### 6. **技術特色**
- 純前端實現（HTML + CSS + JavaScript）
- 非同步載入JSON數據
- 客戶端搜尋和篩選
- 無需後端伺服器
- 快速響應（即時更新）

## 🚀 使用方式

### 方法 1：本地開啟
1. 將整個專案資料夾下載到本地
2. 確保檔案結構完整（特別是 `data/` 資料夾）
3. 用瀏覽器開啟 `code/index_comprehensive.html`
4. 開始瀏覽資料！

### 方法 2：網頁伺服器
```bash
# 在專案根目錄執行
python -m http.server 8000

# 然後在瀏覽器訪問
http://localhost:8000/code/index_comprehensive.html
```
